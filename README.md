# Infinite Canvas

A unified AI art creation platform supporting ComfyUI, API calls, and ModelScope integration.

**Detailed Tutorial:** [https://youtu.be/1y9ShTvgC_w](https://youtu.be/r_y_9ALr7fg)

Due to recent API service disruptions, we recommend this stable provider:

https://apimart.ai/register?aff=1uyAbb

### Update History

### May 13th Update
1. Fixed dependency installation errors
2. Added streamlined API setup - configure entirely through the web interface with one-click model import
3. LLM nodes now support image input for reverse engineering using ModelScope VL models
4. Added Chinese/English language switching
5. Added custom ComfyUI workflow support with configurable inputs and parameters
6. Added video generation capabilities
7. Fixed 2K/4K generation errors
8. Added one-click generation for output nodes via cascade connections

### May 14th Update
1. Fixed several macOS bugs
2. Added ModelScope LoRA support
3. Added OpenAI protocol and asynchronous protocol support (no charge on generation failures)

### May 15th Update
1. Added loop components and counting functionality for N-times concurrent/sequential node execution
2. Added variable prompt support for dynamic text insertion (e.g., "Generate item [Count]")
   - Example: Use Gemini to generate 10 product selling points. Use loop nodes with dynamic prompts to call GPT and generate 10 selling point images concurrently
3. Added protocol verification tool for API platform validation
4. Fixed LLM node bugs
5. Uploaded simplified Python distribution - run "install_dependencies.bat" then "run.bat"
### May 18th Update
5/1Fixed video generation bugs
2. Added brush editing tools
3. Fixed ComfyUI concurrency issues

3. Fixed a concurrency bug in ccomfyui.
